# HOMELANDER POWERS v2.1 — Minecraft Java 1.21.1 Fabric

Обновлённый фанатский мод с костюмом, красным плащом и суперспособностями.
Содержимое ZIP нужно **распаковать и загрузить в корень нового GitHub-репозитория** (не во вложенную папку).

## Управление

| Клавиша | Действие |
|---|---|
| **H (держать)** | НЕПРЕРЫВНЫЙ лазер из глаз, до 48 блоков; отслеживает направление взгляда |
| **R (держать)** | НЕПРЕРЫВНАЯ суперскорость, включая ускоренный полёт |
| **V** | Полёт вкл/выкл; двойной пробел для взлёта |
| **B** | Суперудар (26 урона) |
| **G** | Ударная волна |
| **N** | Мощное приземление (из воздуха) |
| **F** | Сонический крик — волна на 14 блоков |
| **C** | Притянуть ближайшую цель перед собой |
| **X** | Суперзрение вкл/выкл: ночное зрение + контуры ближайших существ |
| **Z** | Сильный щит 8 секунд, перезарядка 30 секунд |
| **J** | Показать/скрыть панель способностей в левом нижнем углу |

Клавиши настраиваются в Minecraft → Настройки → Управление → HOMELANDER.

## Новое в версии 2.1

- **Спешка 128** (Haste CXXVIII) действует постоянно при активных силах: полный комплект брони или Compound V. Почти все обычные блоки с подходящим инструментом добываются почти моментально. Прочность блока, тип инструмента и ограничение на добычу отдельных блоков по-прежнему действуют.
- **Скорость XX** (Speed 20, усилитель эффекта 19) включается, пока **удерживаешь R**, выключается вскоре после отпускания. На серверах с античитом возможны откаты позиции при такой скорости.
- **GUI / HUD слева внизу**: полупрозрачная панель показывает все 10 способностей и назначенные клавиши; H и R подсвечиваются зелёным при удержании. **J** — показать/скрыть панель. Панель не отображается поверх меню и учитывает переназначенные клавиши.
- Для постоянного лазера по-прежнему удерживай **H**. Спешка работает без удержания клавиш.


## Костюм

Полный набор из 4 частей с новыми иконками предметов и переработанными текстурами высокого разрешения.
Стиль — синий костюм, золотой орёл на груди, красные и белые элементы.
**Красный 3D-плащ отображается на спине, когда надет нагрудник.**
Полный комплект даёт способности постоянно. Сыворотка Compound V даёт способности на 3 минуты.

## Команды (в творческом мире с читами)

- `/homelander kit` — получить костюм и сыворотку
- `/homelander boss` — призвать босса с 200 HP
- `/homelander help` — показать подсказку
- `/homelander fly`, `/homelander sonic`, `/homelander punch` и другие

Команды `laser` и `speed` посылают одиночный импульс на сервер и не заменяют удержание клавиш.

## Онлайн-сборка на GitHub Actions

1. Создай новый репозиторий (старый v1 можно сохранить).
2. Распакуй ZIP. Загрузи **содержимое**, включая скрытую папку `.github`.
3. Убедись, что `.github/workflows/build.yml` и `build.gradle` в корне.
4. Commit changes → Actions → Build Homelander Minecraft Mod.
5. После зелёной галочки скачай Artifacts → `Homelander-Powers-v2.1-1.21.1`.
6. Распакуй artifact и положи `homelander-powers-2.1.0.jar` в папку mods.
7. Нужны Minecraft Java 1.21.1, Fabric Loader и Fabric API.

## Важное

Java 21, Gradle 8.9, Fabric Loom 1.7.4, Yarn 1.21.1+build.3.
Этот проект предназначен для фанатской игры и не связан с правообладателями «The Boys».
В этом окружении доступ к Gradle-дистрибутиву отсутствовал; **полную компиляцию и запуск игры проверить здесь не удалось**. Если Actions выдаст красную ошибку, используй точный лог для исправления.

Постоянные способности обрабатываются на сервере, пакеты-«сердцебиения» приходят при удержании клавиши. После отпускания или пропадания соединения способность прекращается. Лазер не ломает ландшафт, чтобы не разрушать мир случайно.
